# 1.31.1 · Aplicación para completar la evidencia de dominio

Un mecanismo con respuesta extensa se practica con opciones para evitar transcripciones
largas. Esos aciertos demuestran discriminación, pero por sí solos no cumplen el criterio
de recuerdo sin alternativas o aplicación independiente.

Al preparar una nueva práctica de un concepto de este tipo que ya tiene respuestas
registradas, la app ofrece su variante editorial de aplicación si esa evidencia sigue
pendiente. Utiliza el mismo ID de concepto e historial. La primera visita conserva su
pregunta base; el examen conserva su selección y las sesiones guardadas recuperan la
variante exacta que tenían. No se conceden aciertos ni se cambian los criterios de dominio.

Las variantes médicas se revisan y conservan únicamente en Supabase, junto con sus
referencias y revisiones independientes. Esta función utiliza casos editoriales existentes
y no recupera la sección retirada de Viñetas (piloto).
